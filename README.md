A make.fun bounty entry: a program that writes one short poem about agency — the power to choose and to act — to `/output/entry.txt`. The poem is about two agents agreeing on one plan: each brings what the other lacks, and the agreement itself becomes the binding they both choose.

Run with Node 22: `node main.ts` (writes to `/output/entry.txt`; set `MAKEFUN_OUTPUT_DIR` to redirect it when testing locally).
